# ADR-005: Online Self-Learning System with Feedback Loop

**状态**：已采纳 | **日期**：2026-04 | **决定者**：架构组

## 背景

Agent 在持续使用中产生了大量工具调用数据（成功/失败/延迟），这些数据可以用于优化未来的决策质量。需要一个学习系统将这些经验反馈到 Agent 行为中。

## 方案

构建 **在线学习系统**，以 FeedbackCollector → ExperienceLearner → AdaptiveOptimizer → EvolutionManager 四阶段闭环运行：

```
工具执行 → FeedbackCollector → ExperienceLearner → AdaptiveOptimizer → Agent Prompt / 路由权重
                                                                                ↑
                                                                  EvolutionManager (定时触发)
```

## 考虑过的选项

### 选项 A：仅统计（无学习）
- 优点：极简单
- 缺点：无法自动改进决策质量

### 选项 B：离线训练（ML 模型）
- 优点：精度高、批处理稳定性好
- 缺点：需要标注数据、训练管道、特征工程、不适合快速迭代

### 选项 C：在线学习（选定）
- 优点：实时反馈、轻量计算、冷启动友好

## 关键设计决策

### 5.1 置信度计算：Wilson 区间

使用 Wilson 置信区间而非朴素成功率：
```python
# 低样本时自动缩紧置信度
n=1, 成功率 100% → Wilson 下限 ~20%  (保守估计)
n=100, 成功率 90% → Wilson 下限 ~83% (可信估计)
```
防止小样本噪声导致错误学习。

### 5.2 策略匹配：TF-IDF + 余弦相似度

使用 TF-IDF 向量化 + 余弦相似度匹配历史策略，而非简单关键词匹配：
```
"搜索最新价格" → TF-IDF → [0.2, 0.8, 0.1, ...]
"查询当前汇率" → TF-IDF → [0.3, 0.7, 0.1, ...]
→ 相似度 0.85 → 推荐相同策略
```

### 5.3 自适应学习率

```python
α = 1 / (1 + 0.1 × n)  # n = 该上下文样本数
# 初始: α ≈ 1.0 (快速学习)
# n=100: α ≈ 0.09 (微调)
# n=1000: α ≈ 0.01 (稳态)
```

### 5.4 反模式检测

从失败路径提取"不该做什么"的模式，反向注入到 Agent 提示词中：
```
反模式: "对不存在文件调用 file_read" → 提示词增加 "验证文件存在再读取"
```

## 后果

- 正：系统在持续使用中自动改进，无需人工干预
- 正：运行开销极低（单次学习周期 ~50ms）
- 负：冷启动阶段（前 50 次调用）策略置信度低
- 负：异常反馈可能污染策略（通过 Wilson 区间缓解）
